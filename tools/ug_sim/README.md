# 지하던전 밸런스 시뮬 (3인 파티 봇)
index.html 의 던전 엔진을 그대로 뽑아 노드에서 돌린다(브라우저 불필요). 숫자는 index.html 의 `UGT`(몹·보스·경험치 배율)·`SUBT`(서브 보스)에서 고친다.
- `node t_ug.js boss 1001 100 1 2 3` — 보스방 클리어 여부(시드 1,2,3). 구성은 마지막 인자 `7,3,5`(기사 번호)
- `node t_ug.js farm 1002 150 3 1` — 사냥 3분: 처치/분·XP%/분·체력손실·사망
- `node t_ug.js sub 1003 200 1 2` — 서브 보스 1:1(시간·체력)
- 임시 배율: `UGT='{"boss":[{"hp":0.4,"atk":0.8},...]}' node t_ug.js ...` (JSON 은 0.4 처럼 앞에 0)
기준 파티 = 해당 레벨, 장비는 드랍 상한(100층) 안에서 후보 20개 중 최선. 봇은 사람보다 약하다.
