# 라운드비 나이츠 — 홍보·활용 기획

작성 2026-11-03 · 기준: 게임 v2.5(라이브 https://ksinvaid.github.io/roundb-night-defense/), 깃 `ksinvaid/roundb-night-defense`(`docs/기획_라운드비나이트_플랫폼개편.md` 포함), 라운드비 채널 현황(블로그·카페·유튜브·인스타·틱톡·노션·카톡 채널).
※ 이름은 사용자가 '라운드비 나이츠'로 정했지만 게임 제목·코드는 아직 '라운드비 야간 방어전'이라, 이 문서는 플랫폼=**라운드비 나이츠**, 대표 게임=**야간 방어전**으로 쓴다.

## 0. 한 장 요약

**포지셔닝 한 줄**: *"우리 사무실이 게임이 됐다."* — 라운드비 3·4층 실제 배치도·사진으로 만든 무료 웹게임. 게임이 곧 **살아 있는 공간 소개서**다.

**솔직한 전제**: 게임 유저와 입주 고객은 겹치는 사람이 적다. 그래서 "게임 → 바로 계약"을 기대하지 않고, 게임을 **(1) 공간을 체험시키는 명함, (2) SNS·블로그 콘텐츠 소재 공장, (3) 입주자 커뮤니티·재계약 도구**로 쓴다. 효과는 숫자로 재야 하는데 지금은 **측정이 0**이라, 첫 주에 측정부터 심는다.

**제일 먼저 막을 구멍 4개 (코드 확인함)**

1. 방문자 측정이 없다 (분석 코드 0개) → 홍보해도 효과를 모른다.
2. 카톡·SNS 공유 미리보기가 없다 (`og:` 메타 태그 0개, 설명문도 없음) → 링크를 보내면 제목 한 줄만 보인다.
3. 결과 화면의 "라운드비 알아보기" 링크가 비어 있다 (`PROMO.link:""`) → 게임을 끝까지 한 사람이 갈 곳이 없다.
4. 카톡 안 브라우저에서 구글 로그인이 막힌다 → 카톡으로 퍼지는 게 주 경로인데 첫 화면부터 막힐 수 있다.

**이번 주 할 일 TOP 5** (전부 0원): ① 공유 미리보기(og)+설명문 ② 결과 화면 문의 링크 연결(UTM 포함) ③ 익명 방문 측정 ④ 사무실 QR 포스터 시안 ⑤ 쇼츠 첫 3편 기획. → 3장 1단계 표 참고.

## 3. 홍보 전략 (4단계)

### 1단계 · 기반 정비 (이번 주, 0원) — "퍼널 배관 먼저"
| 할 일 | 내용 | 누가 |
|---|---|---|
| 공유 미리보기 | `og:title/description/image`(1200×630, 기사단 단체컷+"우리 사무실이 게임이 됐다"), `description`, 아이콘 | Claude(코드)·사용자(문구 확인) |
| 결과 화면 CTA | `PROMO.link` 를 홈페이지 문의/카톡 채널로 + `?utm_source=game&utm_medium=result&utm_campaign=night`, 문구 "라운드비 상담받기" | Claude |
| 상시 작은 링크 | 첫 화면·메뉴에 "입주·대관 문의" (UTM 별도) | Claude |
| 방문 측정 | 익명 집계 도구(GoatCounter·Plausible 같은 쿠키 없는 것, 또는 Firebase Analytics)로 방문·첫 판 시작·결과 도달·CTA 클릭을 센다. 개인정보 수집 없음 | Claude(심기)·사용자(도구 계정 승인) |
| 앱 안 브라우저 | 카톡·인스타 인앱 감지 시 "크롬/사파리로 열기" 안내를 구글 버튼보다 먼저 | Claude |
| 이름 확정 | 나이츠 확정 → 제목·README·메타·구글 로그인 공개 이름 통일 | 사용자 결정 |
| 상담 체크 | 전화·카톡 상담 때 "어디서 보고 오셨어요?"에 '게임' 항목 추가 | 사용자 |
| **이름·소유 정리** | 아래 8번(리스크) — 대표님과 먼저 | 사용자 |

### 2단계 · 내부 시딩 (1~2주차) — "입주자가 먼저 쓰고 퍼뜨린다"
- 사무실 QR 포스터(A4): 엘리베이터 앞·3층 라운지·4층 탕비실·정수기 옆. 문구는 위 샘플. 전부 QR→`?utm_source=poster&utm_medium=offline&utm_campaign=floor3|4`(층별로 쓰면 어느 자리가 효과 있는지 보임).
- 입주자 공지: 기존 카톡방·노션 3·4층 페이지(이미 하위 페이지 있음)에 "이번 주 층 대항전" 한 줄.
- **층 대항전(첫 4주)**: 3층 vs 4층, 사원증 닉네임 합산 점수. 보상은 실제 혜택으로 연결(라운지 1시간·커피 쿠폰·회의실 1회) — 월 5만 원 이내 제안.
- 입주자 소개 혜택: "게임 링크 보내서 지인이 입주하면 월 이용료 할인" — 금액은 대표님 결정.
- 목표: 입주자가 친구에게 카톡으로 링크를 보내게 → **카톡 공유 미리보기(1단계)가 여기서 효과**.

### 3단계 · 콘텐츠 시리즈 (2~6주차) — "쇼츠 3종 × 주 3편"
기존 영상 제작 파이프(PY캡컷·3사 업로드·블로그/카페 포스팅 규칙)를 그대로 쓴다.
| 시리즈 | 편수 | 소재 | 연결 |
|---|---|---|---|
| ① 라운드기사단 소개 | 10편(1인 1편) | 캐릭터 설정·스킬(기사별 공격/필살기 이미 있음)·"이 기사로 해 보기" | 링크: 내 기사 고르기 |
| ② 플레이 하이라이트 | 주 1편 | 지옥 난이도 도전, 터렛 수천 개 소용돌이, 대결 4:4, 층 대항전 중계 | 링크: 해당 모드 |
| ③ 생활·공간 | 주 1편 | 오늘 뭐 먹지 룰렛(밥집 14곳 영상과 교차 링크), 로드뷰 투어 | 링크: 밥집·투어 + 문의 |
- 플랫폼별로 제목·설명·태그를 다르게(기존 규칙). 설명 첫 줄에 링크(UTM: `utm_source=youtube|insta|tiktok`).
- 블로그·카페: ① **개발기**("공유오피스 직원이 AI로 사무실 게임을 만든 이야기") ② **업데이트 노트**(카페 게시판 50, v2.5 아직 안 올림) ③ **공략**(게시판 53) ④ 밥집 시리즈 연계. 블로그는 조회수가 낮으니 검색 키워드(신당역 점심·동대문 공유오피스 + 게임)를 제목에.
- 기억할 것: 게임 영상은 **설명 없이 첫 3초에 장면**(귀신이 문을 두드림)부터.

## 4. 게임을 홍보 말고 어디에 쓰나 (활용안)

1. **영업 도구**: 상담 문의가 오면 "먼저 게임으로 둘러보세요" 링크. 랜선투어(로드뷰)+게임이 공간 소개서 역할 → 방문 상담 전 사전 이해↑.
2. **입주자 커뮤니티·재계약**: 사원증·직급·층 대항전·'이번 주의 게임'(깃 기획) → 입주자가 매주 열게 하는 이유. 재계약 시점 전에 활동 기록을 보여 주는 "올해의 라운드비 사원" 같은 작은 이벤트.
3. **공간 이벤트(대관 홍보)**: 월 1회 라운지 "야간 방어전 대회"(3층 라운지 최대 40인). 대회 자체가 대관 사례·쇼츠·블로그 소재가 된다. 참가 입주자 무료·외부인은 소액 → 대관 문의로 연결.
4. **브랜드 IP**: 라운드기사단을 공식 마스코트로(SNS 프로필·공지 이미지·사원증 목걸이 줄·스티커·포스터). ※ 캐릭터는 AI 생성이라 **상업 이용 약관 확인 필요**(힉스필드, 이미 사용자에게 알림).
5. **지역 상권 제휴**: 밥집 로드를 '입주 혜택'으로 상품화(제휴 가게 1~2곳부터).
6. **고객 목소리**: 게임평 게시판·카페 게임 그룹 = 의견 수집 창구. 입주자 요청(회의실·정수기 등)이 섞여 올라오면 운영에도 쓸 수 있다.
7. **포트폴리오·대외 활동**: 개발기·모두의창업 재도전·지역 콘테스트(사용자 개인 성과이자 라운드비 홍보).
8. **B2B 확장 아이디어(대표님 결정 사항)**: 다른 공유오피스·학원·가게를 위한 "우리 공간 게임 만들기" — 라운드비 게임이 시연 사례. 지금은 아이디어 단계.

3. **캐릭터 권리** — AI 생성 이미지 상업 이용 약관 확인. 굿즈·대외 사용 전에 확인.
4. **서버 한계** — Apps Script(랭킹)·Firebase 무료 한도, PeerJS 공용 서버·TURN 없음. 홍보로 방문이 늘면 멀티 매칭 실패·랭킹 지연이 먼저 터질 수 있어 **첫 경험은 혼자 모드로 안내**하고, 홍보 전에 부하 점검 한 번.
