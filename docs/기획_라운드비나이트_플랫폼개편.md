# 기획: 라운드비 나이트 플랫폼 개편

작성: 2026-11-03, 사용자(카이)와 섭정왕 클루루의 대화를 정리한 기획안. 사용자가 방향을 승인했고("너무 좋다"), 세부는 다음 세션이 사용자와 함께 다듬는다.
기준 판본: v2.5 (index.html 약 1.6MB, 모드: 혼자·다 같이·소용돌이·미로·대결·LORD 영주전·땅따먹기 + 오늘 뭐 먹지·공간 둘러보기)

## 왜 바꾸나 (현재 진단)

1. **정체성이 흐리다.** 제목과 설명은 "방 막고 새벽 6시까지 버텨라"인데, 첫 화면에 LORD 영주전·땅따먹기·오늘 뭐 먹지가 출근하기와 같은 무게로 놓여 있다. 반대로 혼자·다 같이·소용돌이·미로·대결은 출근하기 안에 숨어 있다. 처음 온 사람이 무슨 게임인지 바로 알기 어렵다.
2. **사람이 쪼개진다.** 멀티 모드가 많아 동시 접속자가 적을 때 모드마다 매칭이 비고 결국 AI와 하게 된다.
3. **관리 부담.** 한 파일(1.6MB)에 모든 모드가 들어 있어 폰 첫 로딩이 무겁고, 고칠 때 모드끼리 서로 깨질 위험이 크다.
4. **첫 사용자가 헤맨다.** 사용자의 친구가 2026-11-02에 처음 해 보며 헤맸다. (어디서 헤맸는지는 아직 확인 안 됨 → 아래 "열린 질문")

## 목표

홍보와 사내 게임 **둘 다** 한다 (사용자 결정).
- 외부 방문자: 30초 안에 라운드비 공간을 느끼고, 입주 문의까지 이어지게
- 입주자: 매주 다시 오게

## 1. 이름: 플랫폼과 게임을 나눈다

위플레이처럼 여러 게임이 모인 **플랫폼**으로 간다. 기존 "야간" 세계관(퇴근 후 빈 사무실, 공실 귀신)을 살린다.

| 후보 | 느낌 |
|---|---|
| **라운드비 나이트 (ROUND B NIGHT)** ← 추천 | 퇴근하면 사무실이 놀이터가 된다. 기존 세계관이 그대로 이어짐 |
| 라운드비 오락실 | 직관적, 정겨움. 홍보용으로는 다소 가벼움 |
| 라운드비 플레이 | 위플레이 느낌, 무난하지만 개성 약함 |

- 플랫폼: 라운드비 나이트
- 간판 게임: **야간 방어전** (다 같이 모드가 라운드비만의 게임: 실제 층 배치도·방 사진·협동)
- 그 밖의 게임: LORD 영주전, 땅따먹기, 대결, 소용돌이·미로 등
- 생활 메뉴: 오늘 뭐 먹지, 공간 둘러보기

이름은 아직 **확정 전**. 사용자가 고르면 제목·README·메타 태그를 바꾼다.

## 2. 첫 화면: 층 지도 로비

버튼 목록 대신 **라운드비 3·4층 배치도 자체를 로비**로 쓴다. 방마다 게임 하나를 연결한다.
- 게임을 고르는 행동 자체가 공간 홍보가 된다.
- 예시 배치(실제 방 이름·위치는 사용자 확인 필요):
  - 회의실 → 야간 방어전
  - 큰 방 → LORD 영주전
  - 라운지 → 땅따먹기
  - 탕비실 → 오늘 뭐 먹지
  - 방 사진 → 공간 둘러보기
- 폰에서는 지도 아래에 같은 항목을 카드 목록으로 함께 보여 준다(지도만으로는 누르기 어려움).
- "이번 주의 게임"이 있는 방은 빛나게 표시한다.

## 3. 두 목표를 따로 설계

| | 외부 방문자 (홍보) | 입주자 (사내 게임) |
|---|---|---|
| 목표 | 30초 안에 공간을 느끼게 | 매주 다시 오게 |
| 장치 | 가입 없이 바로 하는 "혼자 방어전" 한 판 → 끝나면 공간 사진 + 입주 문의 버튼 | **이번 주의 게임**, 층 대항전, 밥집 도장 |

**이번 주의 게임(로테이션)**: 모든 모드는 열어 두되, 주마다 모드 하나를 메인으로 정해 보상(RP 배율 등)을 준다. 사람이 한 모드로 모여 매칭 문제도 함께 푼다.

## 4. 사원증 = 프로필 (계정 레이어)

이어하기 코드, RP, 기사 캐릭터를 **사원증 하나**로 묶어 모든 게임이 공유한다. 라운드비 직원증 형식을 살린다.

| 사원증 칸 | 게임에서의 의미 |
|---|---|
| 사진 | 내 기사 캐릭터와 색 (기존 기능 활용) |
| 이름 | 닉네임 (변경 가능) |
| 부서 | 진영: 총무·IT·시설 (대결 진영과 연결) |
| 직급 | 누적 RP로 승진: 인턴 → 사원 → 대리 → 과장 → 팀장 → 이사 |
| 사번·입사일 | 첫 플레이 날짜. 오래 한 사람이 티가 남 |
| 배지 | 모드별 업적 (방어전 클리어, 영주전 1위, 밥집 도장 14개 등) |
| 카드 디자인 | 상점에서 RP로 사는 테마·테두리·목걸이 줄 |

- RP를 쓸 곳이 생긴다(꾸미기).
- 랭킹, 같이 하기 대기실, 결과 화면에 **사원증 미니 카드**를 보여 준다.
- 사원증 화면에 게임별 기록과 기사 컬렉션을 모은다.

### 닉네임 변경 규칙 (초안)
- 중복 금지, 욕설 걸러내기
- 변경 주기 제한(예: 7일에 한 번). 상점에서 "개명권" 판매도 가능
- 랭킹 기록은 **사번 기준**으로 저장해 이름을 바꿔도 기록이 따라가게 한다

## 5. 첫 접속 흐름 (온보딩)

처음 들어오면 바로 **사원증 발급** 화면을 보여 준다.
1. 닉네임 입력 → 기사 고르기 → 부서 고르기 (10초 안)
2. **"구글로 사원증 저장하기"** 버튼을 크게, 그 아래 작게 "나중에 하기" (사용자 의견: 처음에 구글 연동이 뜨는 것도 좋다)
3. 발급 끝 → 로비로 이동, 첫 추천으로 "혼자 방어전 한 판"을 반짝이게 표시
4. 첫 판 안에서는 조작 안내를 짧게 한 단계씩 (WASD/터치, 책상에 앉기, 건설)

⚠️ **카톡 안 브라우저 함정**: 친구에게 링크는 주로 카톡으로 보낸다. 카톡 안 브라우저에서는 구글 로그인이 막힌다(README에도 적혀 있음). 카톡 등 앱 안 브라우저를 감지하면 구글 버튼 대신 **"크롬/사파리로 열기"** 안내를 먼저 띄운다. 이 처리가 없으면 첫 화면부터 막힌다.

## 6. 단계 계획

1. **이름 + 로비 + 사원증 발급(온보딩)**: 효과가 가장 큼
2. **사원증 꾸미기 + 닉네임 변경 + 직급·배지**
3. **이번 주의 게임 + 모드별 플레이 통계**(Firebase에 모드별 플레이 수 기록, 2주 보고 안 하는 모드 정리)
4. **index.html을 게임별 파일로 나누기**: 들어가는 게임만 불러오게 해서 로딩 줄이기

## 열린 질문 (사용자에게 확인)

- 플랫폼 이름: 라운드비 나이트로 확정할지
- 3·4층 실제 방 이름과 배치(로비 지도에 쓸 것)
- 친구가 헤맨 지점: 첫 화면에서 뭘 누를지 몰랐는지, 게임 안 조작을 몰랐는지
- 이번 주의 게임 보상 규모, 직급 승진에 필요한 RP 구간
- 사원증 디자인에 라운드비 실제 사원증 양식을 쓸지
