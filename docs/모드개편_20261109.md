# 신규 모드 4개 대개편 지시서 (2026-11-09)

사용자(송현우) 요청 원문 요지
> 지티피(Codex)가 만든 모드 4개가 완전 별로라서 대대적으로 개편해 달라. 싹 갈아엎어도 된다. 내 지시사항은 마크다운으로 정리돼 있을 테니 그걸 기준으로 많이 발전시켜 달라.
> 메인 화면도 지저분한 건 크기 조절·재배치로 깔끔하게 해도 된다. 맵 안의 방 버튼(핀)은 좌우 사이드 메뉴와 중복이니 없애고, 맵에는 캐릭터끼리 상호작용과 10분마다 나타났다 사라지는 RP 보급박스(누르거나 키보드로 먹기)를 넣자.

※ 사용자가 말한 "내 지시사항 마크다운"은 저장소·ksphone·PC 문서에서 찾지 못했다. 이 문서가 그 역할을 한다. 모드의 **현재 규칙(게임 안 설명문)** 은 유지할 가치가 있는 것만 가져오고, 이 문서의 품질 기준을 우선한다.

## 2. 공통 품질 기준 (모든 모드)
1. **혼자서도 완성**: AI 상대/봇으로 처음부터 끝까지 재미있어야 한다. 온라인은 그 위에 `createArenaRoom` 로 얹는다(방장 권위, 손님은 입력 전송+스냅샷, 메시지 14,000자 미만, 방장 이탈 시 안전 종료).
2. **첫 3분이 재미있게**: 시작 전 1화면 요약(목표·조작 3줄)과 건너뛰기, 첫 판 인게임 힌트, 연습 모드(봇 약함). 모르는 사람이 설명 없이 이해할 수 있어야 한다. `roundbArenaBriefing` 이 있으면 활용.
3. **조작**: PC(키보드+마우스)와 **폰 터치**(가상 조이스틱·버튼, 375×812에서 겹침·잘림 없음, 44px 터치 목표). 키는 `docs/작업룰북.md` §6 던전 단축키·기존 메뉴 키와 겹치지 않게. 나가기 버튼은 항상 보이고 판 중 누르면 확인 한 번.
4. **피드백**: 피격/처치/득점/위험을 눈·귀로 즉시 알 수 있게(화면 흔들림 절제, 히트 번쩍임, 효과음 — 기존 `sfx`·WebAudio 방식 재사용, 소리 켜기/끄기), 점수판·결과 화면·**다시 하기 / 설정 바꾸기 / 나가기** 3버튼.
5. **밸런스·길이**: 한 판 3~8분(블러드는 최대 10분), AI 난이도 3단계(쉬움/보통/어려움), 초보도 첫 판에 한 번은 이길 수 있게. 가벼운 시뮬(AI끼리 10판)로 교착(무한 대치)만 확인.
6. **성능**: 폰 55fps 목표, 프레임 낮으면 해상도·이펙트 자동 절감. 메모리 누수 없이 판 반복.
7. **색약**: 팀·상태는 색+모양+글자. 새 색은 쌍별 구분 확인.
8. **사람 얼굴·개인정보 없음**, 외부 라이브러리·CDN 금지, 큰 이미지 금지(재사용: `img/knights_fixed/*.webp` 전신, `img/knights/*_face.webp`, 층 배치도 `roadview/plan3f.jpg`·`plan4f.jpg`, 기존 몹 그림).
9. **보상**: 판 종료 시 RP 는 기존 `knx.reward.grant(gameId, {...})` 가 있으면 그것으로(없으면 현재 코드가 쓰는 방식 유지). 하루 상한·이중 지급 금지, 30초 안에 나가면 보상 0. 순위는 규칙에 있는 `lb/{게임}` 키만(새 키 필요하면 코드로 만들지 말고 보고).
10. **안정성**: 모드 전체를 `try/catch` 로 감싸 한 모드의 예외가 로비·다른 모드를 죽이지 않게. 콘솔 오류 0.

## 3. 모드별 개편 방향 (현재 코드를 읽고 더 좋은 안이 있으면 그걸로 — 보고에 이유 한 줄)
### 대난투
- 열 명의 기사가 각자 **고유한 4스킬(기본기+이동기+광역/제어+궁극기)** 과 역할(근접 딜러·원거리·탱커·서포터·암살자)을 갖는 **난투 아레나**. 라운드비 3층/4층 배치도를 **전장**으로(책상·정수기·프린터 등 지형지물 = 엄폐·함정·버프 오브젝트).
- 모드: 개인 난투(체력 0 → 3초 뒤 부활, 최다 처치), 팀전 2:2/3:3, 서바이벌(안전지대 축소). 아이템 박스(회복·속도·방어막), 콤보·넉백 손맛. 혼자 하기 = 봇 3~9명.
- 결과: 처치/피해/지원 점수, MVP, RP.
### 진화 블러드
- 군체 RTS 의 핵심 재미를 **단순·명확하게**: 내가 드론(영웅)을 조종하며 자동 생성되는 군체에 **진화 선택**(8종 종 + 업그레이드 트리)을 내리고, 목표 지점을 찍어 **집결·돌격·후퇴 명령**. 적 기지(최대 10기지)를 부수면 승리.
- 자원(혈액/바이오매스)·진화 포인트가 눈에 보이게, 미니맵·군체 수·위험 알림, 폰에서 탭=집결/더블탭=돌격 같은 단순 입력. 한 판 최대 10분, 엘리미네이션/타임어택 선택. AI 기지는 성격이 다르게(공격형·수비형·확장형).
### 암전 순찰
- **어둠과 손전등**이 핵심인 2D 탑다운 전술/잠입: 시야 콘·시야 밖 안개, 소음(달리기·문)이 위치를 노출, 손전등 배터리, 어둠 속 숨기. 2인 팀 × 최대 5팀.
- 목표를 **명확하게**(예: 3개 퓨즈를 찾아 비상 엘리베이터 가동 후 탈출 / 마지막 생존 팀 / 순찰 점령 중 택일 — 하나를 기본으로), 전리품(배터리·열쇠·연막·함정), 라운드비 3F/4F 배치도를 어둡게 재해석한 맵. 봇 팀은 손전등 순찰·소리 추적.
### 라운드비 총격전
- 4층 공유오피스 등 **4개 아레나**의 의사 3D(레이캐스트) 5대5 **설치·해체전**(최대 7라운드, 3라운드 뒤 공수 교대). 구매 단계(주무기 5종 계열·권총·보조), 조준 정확도(이동·연사 퍼짐), 반동, 수류탄·연막, 점수판·킬피드·결과.
- **폰 FPS 조작**(왼쪽 이동 조이스틱·오른쪽 시점·발사/조준/설치 버튼) 완성도가 합격선. 봇 AI(엄폐·교전·설치·해체·로테이션)가 어색하지 않게. 연습장(사격장) 추가 가능.

- **자기 전용 클론에서 작업**: `git clone https://github.com/ksinvaid/roundb-night-defense.git <작업폴더>` (작업폴더는 `D:\Program Files\자비스\11_송현우\라운드비_디펜스게임\작업\<담당이름>\`). 같은 폴더에서 여러 담당이 git 을 쓰면 서로 망가진다.

## 5. 로비(메인 화면) 정리 — 로비 담당
- 지도 위 **방·메뉴 핀 전부 제거**(포털 ▶ 와 캐릭터·NPC·접속자·이름표는 유지). 사이드 메뉴·카드가 그 역할을 한다(카드를 누르면 순간이동 연출 후 입장은 유지).
- 지도의 역할: 캐릭터 간 **상호작용**(다른 기사 누르기 → 인사·하이파이브·이모트·말 걸기·친구 추가·귓속말·사원증, NPC 대화 말풍선), 그리고 **RP 보급박스**: 10분 주기(서버 시계 기준 모두 같은 때·같은 자리)로 지도 위에 나타나 1.5분 뒤 사라지며, 눌러서(또는 가까이 가서 E) 먹는다. 1인 1박스 1회, 하루 상한, 첫 박스는 입장 후 곧 맛보게.
- 화면 전체 배치(사이드 리스트·상단 카드·핫 버튼)는 크기·간격·정렬을 다듬어 깔끔하게.

## 6. 던전 편의성 개선 — 던전 담당 (사용자 추가 지시, 개발 위주)
던전 코드는 `index.html` 안 `dgn*`·`dgr` 묶음(150층, `docs/작업룰북.md` §6 참고). 파일 소유: `index.html` 의 던전 구역만.
1. **126층 보스방 버그**: 보스방에 보스가 없고 재도전 버튼도 없는 빈 방이 되는 문제. 원인 추적(층 번호 126, `DEEP`·`spec()` default 분기, `LOOK` 인덱스, 보스 스폰 조건, 클리어 판정) 후 고치고, 어떤 상태에서도 **보스방에서 보스가 없으면 재생성 + [보스 재도전] 버튼**이 보이게 방어 코드.
2. **이미 깬 층은 시야를 전부 준다**: 클리어한 층을 다시 열면 안개(까만 미탐색 영역) 없이 **전체 지도가 밝게** 보이고 미니맵·지도에 전부 표시(저장 기록의 최고 클리어 층 이하).
3. **시작 지점에 [보스방 바로 가기] 버튼**: 층에 입장한 직후(또는 지도 창)에서 보스방 위치로 이동(걸어가는 경로 표시 또는 즉시 이동 — 보스방 입구까지 순간이동, 몹 없는 안전한 선택). 이미 깬 층은 [포털 바로 가기]·[이전 층 보스방] 도 제공.
4. **파티 편의**: 파티원이 안 와도 **혼자 보스를 깰 수 있고, 혼자 다음 층으로 갈 수 있다**(이미 있으면 확인), 다시 **이전 층 보스방으로 바로 이동**할 수 있는 층 이동 메뉴(내가 깬 층 목록에서 선택 → 해당 층 보스방 앞으로). **파티원 이름을 누르면 [따라가기]**: 그 사람이 다른 층에 있으면 **순간이동으로 그 층·그 사람 옆으로** 이동(보스전 중이면 관전/합류 규칙에 맞게).
5. **매칭 화면 친구 따라가기**: 서버 매칭/방 목록 화면(`server-rooms.js` 의 공개방 목록·서버 매칭 현황, 던전 [온라인 파티] 탭)에 **[친구 따라가기]** 버튼 — 접속 중인 친구(`knx.fr.list()` 의 online)가 어느 방(공개방 목록의 닉네임/presence 의 `dgp-코드-층-인원` 태그 등)에 있는지 찾아 **눌러서 바로 그 방에 입장**. 찾을 수 없으면 이유 안내.
