# 팬아트 갤러리 운영 안내 (2026-11-10)

공개 주소(쓰레드 등에서 링크로 쓰는 주소)
- 갤러리 목록: `https://ksinvaid.github.io/roundb-night-defense/#gallery`
- 작품 하나: `https://ksinvaid.github.io/roundb-night-defense/#gallery/<그림 번호>` (예: `#gallery/ai-sample-final`)
- 게임 안: 로비의 `🖼 팬아트 갤러리` 버튼, 게임 목록 시트의 '생활' → `팬아트 갤러리`

## 받은 그림 걸기

필요한 것: Python 3 + Pillow (`pip install pillow`). 저장소 폴더에서 실행합니다.

```
python tools/add_gallery_item.py "C:/받은그림/아린.png" --title "아린 기사 그림" \
    --artist "별빛토끼" --kind human --source "쓰레드 @starbunny" \
    --note "아린이 제일 좋아서 그렸어요!" --desc "아린이 화살을 쏘는 장면이에요"
git add gallery
git commit -m "Add fan art"
git push        # 5~10분 뒤 공개 페이지에 보여요
```

| 옵션 | 뜻 | 한도 |
|---|---|---|
| `--title` | 제목 (필수) | 40자 |
| `--artist` | **필명** (화면에는 '필명'으로 나와요. 비우면 `익명`) | 20자 |
| `--kind` | `human` = 사람이 그림 / `ai` = AI가 만듦 (필수, 배지 `✋ 사람` / `🤖 AI`) | |
| `--note` | **작가의 한마디** 한 줄. 카드에는 필명 옆에 한 줄로 줄여 보이고, 상세 화면에는 '작가의 한마디'로 전체가 나와요 | 80자(넘으면 경고하고 자름) |
| `--source` | 출처 (예: 쓰레드 아이디) | 40자 |
| `--desc` | 설명 | 200자 |
| `--date` | `2026-11-10` 모양 (비우면 오늘) | |
| `--id` | 그림 번호(영문 소문자·숫자·`-`). 비우면 `날짜-번호` 자동 | 40자 |
| `--dry-run` | 파일을 쓰지 않고 결과만 보기 | |

- 그림 파일은 긴 변 1200px 이하 jpg(`gallery/img/<번호>.jpg`)와 480px 썸네일(`<번호>_t.jpg`)로 줄여 저장합니다. 원본은 건드리지 않고, 사진의 위치·기기 정보(EXIF)는 지워집니다. 투명 배경은 흰색이 됩니다.
- `gallery/items.json` 에는 맨 뒤에 더해지고, 화면에는 **날짜가 새로운 순(같은 날이면 나중에 건 것이 앞)**으로 보입니다.
- 운영자가 내용을 확인한 뒤 거는 방식입니다. **공개 입력 칸은 없습니다**(방문자는 작품 댓글만 남길 수 있음).
- 걸린 목록 보기 `python tools/add_gallery_item.py --list` · 내리기 `python tools/add_gallery_item.py --remove <번호>` (이미지 파일도 함께 지움 — 그 작품의 댓글은 서버에 남으니 필요하면 운영자 모드로 지움).
- `gallery/items.json` 한 항목의 모양: `{id, title, artist(필명), source, kind, date, img, thumb, desc, note}`.

## 댓글

- 작품 상세의 댓글(200자)은 컬렉션 `galleryComments` 에 `itemId` = 그림 번호로 저장됩니다. 그림 없이 한 줄만 남기는 곳은 없습니다(갤러리는 그림이 있어야 갤러리 — 저퀄 환영, 쓰레드로 받습니다).
- 닉네임 12자(마지막 닉네임은 이 기기에 기억), 제출 간격 30초, 최신순. 링크(`http://`·`www.`·`abc.com`·`bit.ly` 같은 도메인 꼴)는 막히고 "계정 이름만 적어 주세요"가 나옵니다. `@이름` 처럼 글자로 적는 것은 됩니다.
- **서버 규칙 게시가 먼저 필요합니다** → [gallery-firestore-rules.md](gallery-firestore-rules.md). 게시 전에는 그림만 볼 수 있고 입력 칸에 "댓글은 곧 열려요"가 보입니다.
- **지우기(욕설·광고)**: 문의·게임평 게시판 맨 아래 `운영자` → 구글 로그인(운영자 모드, 약 50분)을 켠 뒤 갤러리를 열면 댓글 옆에 `삭제`(한 번 더 눌러 확정)가 보입니다. 서버 규칙상 삭제는 운영자 계정만 됩니다.

## 파일

- `gallery.js`, `gallery.css` : 화면·댓글 코드 (index.html 은 로비 버튼 한 줄과 `<link>`/`<script>` 두 줄만 추가)
- `gallery/items.json`, `gallery/img/` : 작품 데이터와 이미지 (`gallery/index.html` 은 별개의 '공간 둘러보기' 페이지)
- `tools/add_gallery_item.py` : 그림 걸기 도구
- 캐시: 코드 고침이 보이지 않으면 `index.html` 의 `gallery.js?v=gl1` / `gallery.css?v=gl1` 숫자를 올립니다.
