# 팬아트 갤러리 운영 안내 (2026-11-10)

공개 주소(쓰레드 등에서 링크로 쓰는 주소)
- 갤러리 목록: `https://ksinvaid.github.io/roundb-night-defense/#gallery`
- 작품 하나: `https://ksinvaid.github.io/roundb-night-defense/#gallery/<그림 번호>` (예: `#gallery/ai-sample-final`)
- 게임 안: 로비의 `🖼 팬아트 갤러리` 버튼, 게임 목록 시트의 '생활' → `팬아트 갤러리`

## 운영자 모드 — 갤러리 화면에서 바로 추가·수정·삭제 (코드·명령 필요 없음)

받은 그림을 갤러리에서 직접 올리고 고칠 수 있어요. 컴퓨터든 폰이든 됩니다.

### 1. 로그인 (한 번에 약 50분)
1. 갤러리를 열고(로비 `🖼 팬아트 갤러리`) 머리글 오른쪽의 **`🔧 운영자`** 를 누릅니다(폰에서는 🔧 만 보여요).
2. 나오는 안내 상자에서 **`구글로 로그인`** 을 누르고 **운영자 구글 계정**으로 로그인합니다. (문의·게임평 게시판의 `운영자` 와 같은 로그인이라, 한 곳에서 켜면 다른 곳도 켜져요. 비밀번호는 게임이 받지 않아요.)
3. 로그인되면 맨 위에 노란 테두리 **운영자 상자**가 생기고, 머리글 버튼이 `🔧 로그아웃` 으로 바뀝니다. 50분이 지나거나 새로고침하면 자동으로 풀리니 다시 로그인하면 돼요. 운영자가 아닌 사람 화면에는 이 상자도, 편집 버튼도 **아예 나타나지 않아요**.
   - "팝업이 막혀 있어요"가 뜨면 주소창 옆에서 팝업을 허용하고 다시 누르세요. 카카오톡 안 브라우저에서는 구글이 로그인을 막으니 크롬·사파리로 여세요.

### 2. 작품 추가
1. 운영자 상자의 **`＋ 작품 추가`** 를 누릅니다.
2. **그림 파일**을 고르면(JPG·PNG·WebP, 25MB까지) 브라우저가 알아서 긴 변 1200px 이하 JPEG와 작은 썸네일로 줄여요. 미리보기와 크기(KB)가 나옵니다. 큰 그림도 용량 한도 안으로 품질을 자동으로 낮춰요.
3. **제목**(필수)·**필명**·**종류**(✋ 사람 / 🤖 AI)·출처·**작가의 한마디**(80자)·설명·날짜를 적습니다. 링크 칸은 없어요(계정은 `@이름` 처럼 글자로만).
4. 바로 공개하지 않고 먼저 보고 싶으면 **"숨긴 채로 저장"** 에 체크 → 저장한 뒤 작품 밑의 `보이기` 를 누르면 공개돼요.
5. **`올리기`** — 새 작품은 맨 앞에 걸립니다.

### 3. 수정 · 숨김 · 순서 · 삭제
작품 카드 밑(또는 작품 상세 화면)에 버튼이 있어요.

| 버튼 | 하는 일 |
|---|---|
| `▲` `▼` | 한 칸 앞/뒤로 옮기기 (위쪽 = 앞) |
| `수정` | 제목·필명·종류·출처·한마디·설명·날짜 고치기. 그림을 바꾸려면 새 파일을 고르고, 안 고르면 그대로예요 |
| `숨기기` / `보이기` | 숨긴 작품은 나한테만 흐리게(🚫 숨김) 보이고 방문자에게는 안 보여요 |
| `삭제` | **두 번 눌러** 확정(3.5초 안에). 그 작품의 댓글도 함께 지워져요. 되돌릴 수 없어요 |
| `원래대로` | (기본 작품만) 고친 글·순서·숨김을 지우고 처음 모습으로 |

- **기본 작품**(`gallery/items.json` 에 파일로 들어 있는 처음 2점 등)도 같은 버튼으로 **숨기기·순서·글 고치기**가 돼요. 다만 그림 파일 자체는 저장소에 있어서 화면에서 지울 수는 없고, 지우고 싶으면 `숨기기` 하거나 아래 명령(`--remove`)을 써요.
- 댓글 옆의 `삭제` 로 욕설·광고 댓글도 지울 수 있어요(두 번 눌러 확정).

### 4. 저장소와 주의
- 화면에서 올린 작품은 Firestore `galleryItems` 에 저장돼요(그림 파일은 문서 안에 들어가요). **서버 규칙을 먼저 게시해야 저장돼요** → [gallery-firestore-rules.md](gallery-firestore-rules.md). 게시 전에는 운영자 상자에 "작품 저장소가 아직 열리지 않았어요"가 나오고 추가·수정은 거절돼요(기본 작품은 그대로 잘 보여요).
- 무료 한도를 아끼려고 목록은 썸네일만, 큰 그림은 작품을 열 때만 읽어요. 저장된 작품 문서(기본 작품 덮어쓰기 포함)는 100개까지만 목록에 담겨요. 90개를 넘으면 운영자 상자에 경고가 나오니 오래된 작품을 정리해 주세요.
- 숨김은 화면에서만 가리는 거예요. 비밀로 해야 할 그림은 올리지 마세요.

## 컴퓨터에서 명령으로 걸기 (선택 — 화면에서 올리는 게 어려울 때)

필요한 것: Python 3 + Pillow (`pip install pillow`). 저장소 폴더에서 실행합니다.

```
python tools/add_gallery_item.py "C:/받은그림/아린.png" --title "아린 기사 그림" \
    --artist "별빛토끼" --kind human --source "쓰레드 @starbunny" \
    --note "아린이 제일 좋아서 그렸어요!" --desc "아린이 화살을 쏘는 장면이에요"
git add gallery
git commit -m "Add fan art"
git push        # 5~10분 뒤 공개 페이지에 보여요
```

| 옵션 | 뜻 | 한도 |
|---|---|---|
| `--title` | 제목 (필수) | 40자 |
| `--artist` | **필명** (화면에는 '필명'으로 나와요. 비우면 `익명`) | 20자 |
| `--kind` | `human` = 사람이 그림 / `ai` = AI가 만듦 (필수, 배지 `✋ 사람` / `🤖 AI`) | |
| `--note` | **작가의 한마디** 한 줄. 카드에는 필명 옆에 한 줄로 줄여 보이고, 상세 화면에는 '작가의 한마디'로 전체가 나와요 | 80자(넘으면 경고하고 자름) |
| `--source` | 출처 (예: 쓰레드 아이디) | 40자 |
| `--desc` | 설명 | 200자 |
| `--date` | `2026-11-10` 모양 (비우면 오늘) | |
| `--id` | 그림 번호(영문 소문자·숫자·`-`). 비우면 `날짜-번호` 자동 | 40자 |
| `--dry-run` | 파일을 쓰지 않고 결과만 보기 | |

- 그림 파일은 긴 변 1200px 이하 jpg(`gallery/img/<번호>.jpg`)와 480px 썸네일(`<번호>_t.jpg`)로 줄여 저장합니다. 원본은 건드리지 않고, 사진의 위치·기기 정보(EXIF)는 지워집니다. 투명 배경은 흰색이 됩니다.
- `gallery/items.json` 에는 맨 뒤에 더해지고, 화면에는 **날짜가 새로운 순(같은 날이면 나중에 건 것이 앞)**이 기본 순서이고, 운영자 모드에서 순서를 바꾸면 그 순서가 우선해요.
- 운영자가 내용을 확인한 뒤 거는 방식입니다. **공개 입력 칸은 없습니다**(방문자는 작품 댓글만 남길 수 있음). 이 명령으로 건 작품은 `gallery/items.json` 의 기본 작품이 되고, 화면의 운영자 모드에서 숨기기·순서·글 고치기를 할 수 있어요.
- 걸린 목록 보기 `python tools/add_gallery_item.py --list` · 내리기 `python tools/add_gallery_item.py --remove <번호>` (이미지 파일도 함께 지움 — 그 작품의 댓글은 서버에 남으니 필요하면 운영자 모드로 지움).
- `gallery/items.json` 한 항목의 모양: `{id, title, artist(필명), source, kind, date, img, thumb, desc, note}`.

## 댓글

- 작품 상세의 댓글(200자)은 컬렉션 `galleryComments` 에 `itemId` = 그림 번호로 저장됩니다. 그림 없이 한 줄만 남기는 곳은 없습니다(갤러리는 그림이 있어야 갤러리 — 저퀄 환영, 쓰레드로 받습니다).
- 닉네임 12자(마지막 닉네임은 이 기기에 기억), 제출 간격 30초, 최신순. 링크(`http://`·`www.`·`abc.com`·`bit.ly` 같은 도메인 꼴)는 막히고 "계정 이름만 적어 주세요"가 나옵니다. `@이름` 처럼 글자로 적는 것은 됩니다.
- **서버 규칙 게시가 먼저 필요합니다** → [gallery-firestore-rules.md](gallery-firestore-rules.md). 게시 전에는 그림만 볼 수 있고 입력 칸에 "댓글은 곧 열려요"가 보입니다.
- **지우기(욕설·광고)**: 문의·게임평 게시판 맨 아래 `운영자` → 구글 로그인(운영자 모드, 약 50분)을 켠 뒤 갤러리를 열면 댓글 옆에 `삭제`(한 번 더 눌러 확정)가 보입니다. 서버 규칙상 삭제는 운영자 계정만 됩니다.

## 파일

- `gallery.js`, `gallery.css` : 화면·댓글 코드 (index.html 은 로비 버튼 한 줄과 `<link>`/`<script>` 두 줄만 추가)
- `gallery-admin.js` : 운영자 도구(로그인·추가·수정·삭제·숨김·순서). `🔧 운영자` 를 눌렀을 때만 내려받아서 일반 방문자는 받지 않아요
- `gallery/items.json`, `gallery/img/` : 기본 작품 데이터와 이미지 (`gallery/index.html` 은 별개의 '공간 둘러보기' 페이지). 화면에서 올린 작품은 여기가 아니라 Firestore `galleryItems` 에 저장돼요
- `tools/add_gallery_item.py` : 명령으로 그림 걸기 도구(기본 작품 파일을 늘림)
- 캐시: 코드 고침이 보이지 않으면 `index.html` 의 `gallery.js?v=…` / `gallery.css?v=…` 숫자(운영자 도구는 `gallery.js` 안의 `gallery-admin.js?v=…`)를 올립니다.
