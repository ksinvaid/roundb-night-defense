# 라운드비 야간 방어전

라운드비 공유오피스를 소재로 한 웹 디펜스 게임 프로토타입입니다.
방 하나를 골라 문을 막고 설비를 지으며, 새벽 6시까지 공실 귀신을 막아 내세요.

- 클릭·터치로 플레이합니다. 설치 없이 브라우저에서 바로 열립니다.
- 게임 파일은 `index.html` 하나와 `img/` 폴더입니다.
- 방 10곳: 회의실·창고·화장실·실외기실, 그리고 문이 없는 개방형 호리존 스튜디오·휴게공간
- 난이도: 쉬움 · 보통 · 어려움
- **공간 둘러보기**: 게임 속 방들의 실제 사진(`img/gallery/`)을 볼 수 있고, 플레이 중에도 지키는 방의 실제 모습이 함께 나옵니다.

## 모드

- **혼자**: 방을 골라 들어가 지키는 기본 모드. 랭킹 도전은 이 모드만 올라갑니다.
- **다 같이**: 실제 층 배치도를 본뜬 한 층(3F 라운지 / 4F 공유오피스)이 한 판의 무대입니다.
  - 가운데 탁 트인 사무 공간을 두고 위·아래 벽을 따라 방 5개가 있습니다. 시작하면 아바타로 직접 걸어가(WASD·클릭) 책상에 앉으면 그 방의 문이 닫힙니다.
  - 문이 뚫려도 바로 쓰러지지 않습니다. 체력이 남아 있는 동안 다른 사람 방으로 달려가 문을 고치고 도울 수 있고, 홀에서 귀신에게 맞으면 쓰러집니다.
  - 화면을 끌거나 왼쪽 아래 층 지도(미니맵)를 눌러 층 전체를 구경할 수 있습니다. 보스가 오는 길도 표시됩니다.
  - **사람 찾아서 같이 하기**: 최대 1분 동안 같이 할 사람을 찾고(인원이 모이면 바로 시작), 모자란 자리는 AI 동료가 채웁니다. **AI와 바로 시작** 버튼도 있습니다.

## 온라인 다 같이에 대해

- 사람끼리 직접 연결(WebRTC)하며, 연결을 이어 주는 일에는 무료 공개 서비스 [PeerJS](https://peerjs.com) 를 사용합니다. 이 서비스는 "사람 찾기"를 누를 때만 불러옵니다.
- 같이 하는 사람끼리는 서로의 IP 주소가 보일 수 있습니다(웹 P2P 방식의 특성).
- 방장 브라우저가 게임을 계산하므로, 방장이 나가면 그 판은 끝납니다. 손님이 나가면 AI가 이어받습니다.
- 회사·학교 망처럼 직접 연결이 막힌 곳에서는 사람 찾기가 실패하고 AI와 시작합니다.

## 사진

`img/gallery/` 의 사진은 라운드비 사무실을 촬영한 것으로, 입주자 개인 물품·얼굴·모니터 화면이 보이는 사진은 제외하고 골랐습니다.
