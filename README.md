# 라운드비 야간 방어전

라운드비 공유오피스를 소재로 한 웹 디펜스 게임 프로토타입입니다.
방 하나를 골라 문을 막고 설비를 지으며, 새벽 6시까지 공실 귀신을 막아 내세요.

- 클릭·터치로 플레이합니다. 설치 없이 브라우저에서 바로 열립니다.
- 게임 파일은 `index.html` 하나와 `img/` 폴더입니다.
- 방 10곳: 회의실·창고·화장실·실외기실, 그리고 문이 없는 개방형 호리존 스튜디오·휴게공간
- 난이도: 쉬움 · 보통 · 어려움
- 문 체력은 모든 방에 막대로 보이고, 층 지도는 화면 아래에 따로 있어요. 홈페이지·카카오톡 채널·유튜브 바로가기도 있어요.
- **공간 둘러보기**: 게임 속 방들의 실제 사진(`img/gallery/`)을 볼 수 있고, 플레이 중에도 지키는 방의 실제 모습이 함께 나옵니다.

## 업데이트 v2.5 (2026-11-03)

- **오늘 뭐 먹지? (신당역 밥집 14곳)**: 첫 화면의 새 버튼에서 라운드비에서 걸어서 갈 수 있는 밥집을 **뽑기**로 골라요. 종류(밥·면·중일양식·고기·분식)와 거리(코앞 100m 안 / 걸어서 2분대 / 조금 멀리)로 후보를 줄일 수 있고, 뽑은 곳은 메뉴·거리·걷는 시간·영상(유튜브 쇼츠)·네이버지도 링크가 카드로 나와요. 라운드비를 가운데 둔 **개념도 지도**(핀을 누르면 가게 카드)와 거리별 **목록**, 가 본 곳에 찍는 **도장 14칸**(이 브라우저에만 저장, '가 본 곳은 빼고 뽑기' 가능)도 있어요.
- 거리는 네이버지도 캡처로 어림한 값(±10%)이고, 가격·영업시간은 담지 않았어요(가기 전에 네이버지도에서 확인). 가게 사진은 라운드비 유튜브 '근처 밥집' 시리즈에서 찍은 음식 사진이에요(`img/lunch/`). 색 5가지에 모양(●■▲◆✚)을 같이 써서 색을 구분하기 어려워도 알아볼 수 있어요.

## 업데이트 v2.4 (2026-11-03)

- **개인방(방 코드)**: 다 같이·소용돌이·미로·대결·LORD 영주전·땅따먹기 모두 [사람 찾아서 같이 하기]를 누르면 **빠른 매칭 / 방 만들기 / 방 코드 입력 / 혼자 하기** 선택창이 먼저 떠요. 방을 만들면 4글자 코드와 **초대 링크**가 나오고, 친구가 코드를 넣거나 링크를 열면 바로 들어와요(방장이 [시작]을 눌러야 시작, 모자란 자리는 AI). 대결은 방 안에서 4:4·1:7 같은 팀 구성과 진영·AI 난이도를 정해요.
- **모든 모드 멀티**: **LORD 영주전**과 **땅따먹기**도 온라인이 돼요(사람 최대 6명 + 모자란 자리는 AI). 온라인 판은 랭킹·RP에는 올라가지 않아요.
- **방장이 나가도 이어져요**: 방장 연결이 끊기면 남은 사람 중 한 명이 새 방장이 되어 마지막 저장 시점(5~10초 전)부터 이어 가고, 나간 사람 자리는 AI가 맡아요(5개 온라인 모드 모두).
- **방장이 창을 가려도 안 멈춰요**: 방장 화면이 알트탭으로 가려져도 판이 실시간으로 진행돼요. 연결이 잠깐 끊겨도 자동으로 다시 이어요. **방장 배속**(1~3배)은 다 같이·소용돌이·미로에서 방장이 정하고 손님 화면에는 표시돼요.
- **인원수에 따른 몹 조절**(다 같이): 사람(과 AI 동료)이 늘면 귀신 체력과 수가 완만히 늘어요. 혼자일 때 난이도는 그대로예요. 시작 화면에 몇 배인지 한 줄로 나와요.
- **병력 이동 명령이 싸움보다 먼저**: 대결은 우클릭=이동(싸우던 중에도 바로 감), A 누르고 클릭·Shift+우클릭·[공격 이동]=공격 이동이에요. LORD 돌격·수비·따라와, 다 같이 집결 지점도 싸우던 중에 바로 움직여요.

## 업데이트 v2.3 (2026-11-02)

- **새 모드**: **LORD 영주전**(큰 맵에서 영토·건물·병력·가운데 용으로 겨루는 땅따먹기, 실시간 순위) · **땅따먹기**(라운드비 3층·4층 배치도 입체 모형 위에서 선을 그어 영역을 넓히는 모드, 꼬리를 끊기면 사망, 실시간 영역 순위).
- **대결 개편(스타크래프트풍)**: 최대 4:4 · 1:7 같은 자유 팀 구성, 3개 진영(총무·IT·시설)과 진영별 유닛 7종, 공격 목표 버튼, 전장의 안개(적진은 검게, 미니맵은 보이는 곳만 밝게), 팀 구분(▲ 우리 / ◆ 상대), 더 강해진 AI.
- **실시간 순위판**: 게임 중 순위가 1초마다 갱신돼요. 소용돌이·미로 방어전 전체 랭킹이 생겼고, 랭킹 화면은 10초마다 자동 새로고침돼요.
- **상점 확장**: 항목이 크게 늘었고 모드별 구획으로 나뉘며, 포인트(RP)는 모든 모드가 공통이에요.
- **문의·게임평 게시판**(공개/비공개, 운영자 답변), **광자포식 둥근 구체 공격 효과**, **모바일 터치 조작**(가상 조이스틱·행동 버튼·길게 누르기·핀치), 기사 10명 크기 보정, **이어하기 코드 + 구글 계정 연동**(아래), 특가 이벤트 바로가기.

## 모드

- **혼자**: 한 층을 걸어 다니며 원하는 방의 책상에 앉아 지켜요(AI 없이 나 혼자). 랭킹은 '혼자' 탭에 올라가요.
- **다 같이**: 실제 층 배치도를 본뜬 한 층(3F 라운지 / 4F 공유오피스)이 한 판의 무대입니다.
  - 가운데 탁 트인 사무 공간을 두고 위·아래 벽을 따라 방 5개가 있습니다. 시작하면 아바타로 직접 걸어가(WASD·클릭) 책상에 앉으면 그 방의 문이 닫힙니다.
  - 문이 뚫려도 바로 쓰러지지 않습니다. 체력이 남아 있는 동안 다른 사람 방으로 달려가 문을 고치고 도울 수 있고, 홀에서 귀신에게 맞으면 쓰러집니다.
  - 화면을 끌거나 왼쪽 아래 층 지도(미니맵)를 눌러 층 전체를 구경할 수 있습니다. 보스가 오는 길도 표시됩니다.
  - 문이 뚫려도 바로 끝나지 않아요: 방 안 설비에 체력이 있어서 **최후의 항전**을 할 수 있고, 문을 다시 막으면 이어서 싸워요.
  - **건설(B·숫자 1~6)**: 내 캐릭터 둘레(점선 원) 어디든 지어요. 방 안에는 방 설비(칸 수 한도), 복도에는 전자렌지·정수기·조명·책상 방벽을 자유롭게 지어 방어선·미끼로 쓸 수 있어요.
  - **전투 유닛(7·8·9)**: 인턴(근접)·대리(원거리)·팀장(탱커)을 뽑아 집결 지점(우클릭·G)에서 싸우게 해요. 걷는 동안 아바타도 가까운 귀신을 자동으로 때려요.
  - 방마다 **보조석**이 있어 동료 방에 같이 앉아 싸울 수 있고, 쓰러져도 22초 뒤 입구에서 **부활**해요(그동안 유령 소화기로 도움).
  - 순위는 **점수 하나**로 정해져요: (처치×10 + 방 버틴 초×4 + 도움×60 + 보조석 초×3 + 보너스) × 난이도 배율. 결과 화면에 계산이 그대로 나오고, 다 같이 랭킹에도 올라가요.
  - **사람 찾아서 같이 하기**: 최대 1분 동안 같이 할 사람을 찾고(인원이 모이면 바로 시작), 모자란 자리는 AI 동료가 채웁니다. **AI와 바로 시작** 버튼도 있습니다.

## 온라인 다 같이에 대해

- 사람끼리 직접 연결(WebRTC)하며, 연결을 이어 주는 일에는 무료 공개 서비스 [PeerJS](https://peerjs.com) 를 사용합니다. 이 서비스는 "사람 찾기"를 누를 때만 불러옵니다.
- 같이 하는 사람끼리는 서로의 IP 주소가 보일 수 있습니다(웹 P2P 방식의 특성).
- 방장 브라우저가 게임을 계산합니다. 방장이 나가면 남은 손님 한 명이 새 방장이 되어 마지막 저장 시점부터 이어 가고(첫 저장이 나가기 전인 시작 직후 몇 초는 제외), 손님이 나가면 AI가 이어받습니다.
- 서로 다른 와이파이·LTE 사이에서는 직접 연결이 안 될 수 있어요(TURN 중계 서버를 쓰지 않아요).
- 회사·학교 망처럼 직접 연결이 막힌 곳에서는 사람 찾기가 실패하고 AI와 시작합니다.

## 이어하기 코드

- 첫 화면의 **이어하기 코드**에서 코드를 받으면(플레이 기록이 생기면 알아서 만들어져요), 다른 폰·PC에서 그 코드를 입력해 기록(사원증 포인트·강화·소용돌이/미로 기록·내 기사와 색)을 이어서 할 수 있어요. 로그인이 필요 없어요.
- 기록은 [Firebase](https://firebase.google.com)(익명 로그인 + Firestore, 서울 리전)에 저장되고, 닉네임·점수·강화 같은 게임 기록만 담겨요. 이름·연락처 같은 개인정보는 받지 않아요.
- 코드를 아는 사람은 누구나 불러올 수 있으니 남에게 알려 주지 마세요. 두 기기에서 따로 저장해 기록이 엇갈리면 게임이 알려 주고 어느 쪽을 쓸지 고르게 해요.
- **구글 계정 연동(선택)**: 연동해 두면 코드를 잃어버려도 구글 로그인만으로 기록을 이어서 할 수 있어요. 누르기 전에 어떤 정보가 쓰이는지 먼저 안내하고 동의를 받아요. 저장되는 건 구글 계정의 고유 번호와 연결한 이어하기 코드이고(이메일·이름은 Firebase 로그인 목록에 기록되며 이 게임은 쓰지 않아요), '연동 풀기'로 언제든 지울 수 있어요. 연동하지 않으면 구글 정보는 쓰이지 않아요. 카카오톡 같은 앱 안 브라우저에서는 구글이 로그인을 막으니 크롬·사파리로 열어 주세요.
